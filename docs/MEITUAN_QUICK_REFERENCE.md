## 💡 常用场景

### 1️⃣ 推广效果分析
```
用户："帮我做一份推广效果周报"

Agent 自动执行：
1. 抓取推广通活动列表
2. 抓取每日推广统计数据
3. 抓取订单数据
4. 计算 ROI、转化率
5. 生成周报
```

### 2️⃣ 订单数据查询
```
用户："上周有多少订单？总金额多少？"

Agent 自动执行：
1. 抓取订单数据（日期范围过滤）
2. 统计订单数量和总金额
3. 返回结果
```

### 3️⃣ 推广优化建议
```
用户："哪些推广活动效果不好？"

Agent 自动执行：
1. 抓取所有推广活动
2. 对比 CTR、CPC、ROI
3. 识别低效活动
4. 提供优化建议
```

## ⚠️ 重要提醒

✅ **可以做的**：
- 直接描述需求，Agent 会自动选择合适的工具
- 指定时间范围（使用自然语言或 ISO 格式）
- 组合多个查询（如"推广数据 + 订单数据"）

❌ **不要做的**：
- 同时发起多个请求（会排队执行）
- 手动拼接 URL 或发送 HTTP 请求
- 设置 `includeRecords=true`（会占用大量上下文）
