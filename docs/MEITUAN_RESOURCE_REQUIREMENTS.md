- **类型**：商家账号（非普通用户账号）
- **需要**：

  - 商家权限（能访问订单、商品、推广数据）

**当前状态**：❌ 代码中只有通用登录逻辑，未针对美团优化

**需要开发者**：

2. 确认登录流程（账号密码？短信验证？扫码？）

#### 2. **真实页面结构信息**
- **用途**：DOM 选择器需要匹配实际页面
- **当前代码**：使用通用选择器（如 `.order-list`, `.campaign-item`）
- **问题**：这些选择器是**假设的**，可能与真实页面不符

**需要开发者**：
1. 打开美团经营宝页面（https://ecom.meituan.com/meishi）
2. 提供以下页面的 HTML 结构：
   - 订单列表页
   - 商品列表页
   - 商品评价页
   - 推广通活动页
   - 推广数据统计页

**或者**：
- 提供页面截图 + 开发者工具中的 DOM 结构
- 或者直接让开发者在真实环境调试选择器

---

#### 3. **API 接口信息**
- **用途**：XHR 拦截需要知道 API URL 模式
- **当前代码**：使用通用模式（如 `/order/list`, `/api/promotion`）
- **问题**：这些 URL 是**假设的**，可能与真实 API 不符

**需要开发者**：
1. 打开 Chrome DevTools → Network 面板
2. 刷新页面，查看实际请求的 API
3. 提供以下信息：
   - 订单列表 API URL
   - 商品列表 API URL
   - 评价列表 API URL
   - 推广活动 API URL
   - 推广统计 API URL

**或者**：
- 提供 Network 面板的截图
- 或导出 HAR 文件（包含所有请求）
